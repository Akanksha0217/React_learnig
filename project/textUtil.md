### 📝 TextUtils – React Text Utility App

TextUtils is a simple and user-friendly React-based text utility application that allows users to analyze and manipulate text easily. It provides multiple features such as text transformation, text analysis, copy functionality, and text-to-speech support.
_______________________________________________________________________

## 🚀 Features

- 🔠 Convert text to Uppercase
- 🔡 Convert text to Lowercase
- ❌ Remove Special Characters
- 🔢 Remove Numbers
- 🧹 Remove Extra Spaces
- 🔤 Count Vowels
- 🔤 Count Consonants
- 📋 Copy Text to clipboard
- 🔊 Text to Speech (Speaker support)
- 👀 Preview the entered text
- 🔔 Popup alerts for each action (e.g., “Text converted to Uppercase”)
